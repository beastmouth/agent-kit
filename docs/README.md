# agent-kit 文档

脚手架的设计与使用文档。代码在仓库根目录，示例在 [`examples/`](../examples/README.md)。

---

## 按角色选阅读路径

**第一次接触（30 分钟）**
[02-快速开始](02-快速开始.md) → 跑一遍 [examples](../examples/README.md) → [01-架构设计](01-架构设计.md)

**要接一个真实业务**
[06-接入清单](06-接入清单.md) 打勾为主 → 遇到问题查 02 的启动失败对照表 → 配记忆看 [03-会话与记忆](03-会话与记忆.md)

**要改脚手架内部**
[01-架构设计](01-架构设计.md) 的七个设计决策 → 对应模块源码 → 改完跑 [黄金集](05-质量评测.md)

**要决定用哪套引擎**
[08-引擎选型](08-引擎选型.md)：依赖怎么加、配置怎么写、两套差异在哪、怎么回滚

**要上线运维**
[04-可观测性](04-可观测性.md) 的指标与告警 → [07-配置参考](07-配置参考.md) → [06-接入清单](06-接入清单.md) §9 上线前自查

## 版本

文档对应 `agent-kit 0.1.0`。

- `docs/` 与代码同仓库、同 PR 更新，不单独发版
- 示例（`examples/`）不在默认构建里，用 `mvn -Pexamples` 才编
